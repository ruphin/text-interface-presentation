Interfaces

History, present, and future

Introduce yourself. This talk walks through where interfaces came from, where they are now, and why text is about to matter again.

An interface is the gateway through which a user interacts with our product. Everything the user does passes through it, and everything the product gives back passes through it too. The product can be brilliant, but the user only ever meets the interface.

Context matters

A good interface is not good in the abstract. It is good for a user, in a place, with a device, with a goal, at a moment. Change any of those and the right interface changes with it.

Context changes

And context does not sit still. Each time the way people reach us changes, the interface that worked before stops working. Point at the next slide: this has already happened several times.

The storefront: you walked in, a person helped you. The desktop: a screen, a keyboard, a mouse, and a lot of room. The phone: a thumb and a small screen, anywhere. Each shift forced a rethink of the interface, not the product.

And now this. A box you type into, and something that types back. The newest interface looks like the oldest one: a conversation.

Same picture, different focus. The user changed. The user is no longer only a person. Increasingly it is an agent acting on a person's behalf, and that agent reads and writes text.

Swap the person for an agent and the picture holds. The agent is a user too. It arrives through the same gateway, with the same goal, but with none of the eyes, hands, or patience the interface assumed.

Now the chain has two interfaces. The person still talks to an interface, but that interface is the agent's. The agent then needs an interface of its own to reach our product. That second interface is the one we have to build, and the agent speaks text.

text

The interface an agent needs is text. Not a screen it has to look at, not buttons it has to find. Words in, words out. That is what we build next.
